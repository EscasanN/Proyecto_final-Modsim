# Salidas locales del panel

Esta carpeta recibe las ejecuciones iniciadas desde el panel de presentación.
Los archivos de ejecución y logs se excluyen de Git mediante el `.gitignore`
local: pueden regenerarse y los comandos de los logs contienen rutas del equipo.
No se eliminan automáticamente al cerrar el panel.

El panel y sus tareas se describen en `docs/presentation.md`.
Las evidencias sintéticas de referencia permanecen en
`results/experiments/synthetic/` y `results/validation/synthetic/`.
